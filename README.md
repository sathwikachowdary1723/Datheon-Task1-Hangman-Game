# Hangman Word Guessing Game

## About the Project
The Hangman Word Guessing Game is a Python-based console application in which the player attempts to guess a randomly selected hidden word by entering letters one at a time.

The player has a maximum of six incorrect guesses to identify the word before the game ends.

## Features
- Random word selection
- Interactive letter guessing
- Displays correctly guessed letters
- Tracks previously guessed letters
- Prevents duplicate guesses from reducing attempts
- ASCII hangman visualization
- Input validation
- Six incorrect attempts limit
- Victory and defeat messages

## Technologies Used

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Execute the following command:

```bash
python hangman.py
```

6. Enter letters when prompted to guess the hidden word.

## Game Rules
- Guess the hidden word one letter at a time.
- Correct guesses reveal the letters in the word.
- Incorrect guesses add a part to the hangman drawing.
- You have six incorrect attempts.
- Repeated guesses do not reduce your remaining attempts.
- Guess the complete word before the hangman drawing is completed to win.
